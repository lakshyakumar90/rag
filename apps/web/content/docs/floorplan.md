## How to read the map

Select a node to inspect its source group. Follow arrows to see how a request or task crosses a boundary. Use the **Flows** menu to walk through document indexing, a grounded answer, or public documentation. The downloaded HTML can be opened on its own.

## Updating the map

The authored map is in `docs/floorplan/architecture.json`. It groups relative repository paths into components, defines their dependencies, and labels the steps of each flow. The [file guide](/docs/repository) explains the roles of individual files. See [Operations and recovery](/docs/operations#regenerate-the-floorplan) for the export command.
